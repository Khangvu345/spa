## Những gì đã làm được

- [x] Tạo schema `stock_ledger` (collection `stock_ledger`) với 5 index theo spec, `timestamps: { createdAt: 'created_at', updatedAt: false }` để đảm bảo immutable
- [x] Tạo 6 DTO: `StockInDto`, `StockOutManualDto`, `QueryLedgerDto`, `LedgerResponseDto`, `LowStockResponseDto`, `StockSummaryQueryDto`/`StockSummaryResponseDto`
- [x] Service `StockLedgerService` với MongoDB transaction (`connection.startSession().withTransaction()`):
  - `stockIn(dto, user)` — verify material+supplier `isActive`, snapshot stockBefore/After + supplier info + totalCost, self-ref `referenceId`
  - `stockOutManual(dto, user)` — verify material tồn tại (không check isActive), cho phép stock âm, reason bắt buộc qua DTO
  - `findAll(query)` — pagination + filter (materialId, transactionType, referenceType, fromDate, toDate) + sort
  - `findByMaterial(materialId, query)` — wrapper auto inject materialId filter
  - `findByReference(type, id)` — sort asc theo created_at để giữ thứ tự trừ kho của 1 invoice

  - `deductForInvoice(materialId, qty, reason, invoiceId, user, session)` — internal helper, không validate isActive, không reject stock âm, dùng session truyền vào
- [x] Controller `StockController` mount `/stock` với 7 endpoint, `@Roles(ADMIN)` cho POST + summary + low-stock, JWT mọi role cho GET ledger
- [x] Module `StockLedgerModule` import `MaterialModule` + `SupplierModule`, export `StockLedgerService` + `MongooseModule`
- [x] Đăng ký module vào `app.module.ts`

## Vướng mắc / Quyết định kỹ thuật

- **Transaction yêu cầu replica set** — Mongo local single-node sẽ fail. Issue đã chốt: dev tự setup Docker Compose 1-node replica set hoặc dùng Atlas. Khi smoke test cần verify môi trường.
- **`performedByName` snapshot = `currentUser.email`** — `AuthenticatedUser` interface không có `fullName`. Issue spec gợi ý `currentUser.fullName ?? 'Unknown'`, nhưng lookup Staff thêm 1 query mỗi call. Chốt dùng email cho gọn; nếu UI cần tên đầy đủ → bổ sung `fullName` vào JWT payload và `AuthenticatedUser`.
- **`stockOutManual` không check `material.isActive`** — admin có thể cần xuất kho dọn dẹp material đã ngừng dùng. Chỉ verify tồn tại.
- **`referenceId` self-ref cho STOCK_IN/OUT_MANUAL** — pre-allocate `ObjectId` trước insert để gán `_id = referenceId`, cho phép `GET /stock/ledger/by-reference/STOCK_IN/:id` trả về chính entry đó.
- **Endpoint controller path `/stock`** dù module folder là `stock-ledger` — bám sát Issue API table.
