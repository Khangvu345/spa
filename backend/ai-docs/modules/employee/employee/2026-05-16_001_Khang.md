## Lý do thay đổi

- Issue #04 yêu cầu quản lý tài khoản nâng cao nhưng không tạo module mới, nên mở rộng trực tiếp Employee module và Auth guard hiện có.
- Token cũ có `mustChangePassword = true` vẫn bị guard block theo yêu cầu; sau khi đổi password thành công backend trả token mới để FE thay thế.
- Soft delete đổi email sang format `original@email.com.deleted.<timestamp>` để unique index Mongo vẫn cho tạo nhân viên mới bằng email cũ.
