# Issue #03: Module Employee CRUD đầy đủ

## Nội dung Issue (paste nguyên văn)

## Mô tả

Implement CRUD đầy đủ cho module Employee — list, detail, create, update với search, filter, sort. Build trên Staff schema đã có từ Issue #02.

## Nghiệp vụ (User stories)

- **EMP-01 Thêm nhân viên:** Admin tạo nhân viên mới với email + password ban đầu
- **EMP-02 Gán vai trò:** Admin chọn role khi tạo/sửa (bắt buộc 1 role)
- **EMP-03 Cập nhật:** Admin chỉnh sửa thông tin (full_name, phone, role, base_salary, started_at, work_status) — KHÔNG cho sửa email và password qua endpoint này
- **EMP-07 Xem danh sách:** Pagination, mặc định 10 items/page
- **EMP-08 Xem chi tiết:** Full info để admin review trước khi edit
- **EMP-09 Tìm kiếm:** Theo full_name hoặc email, không phân biệt hoa thường
- **EMP-10 Lọc theo vai trò:** Filter by role
- **EMP-11 Lọc theo trạng thái làm việc:** Filter by work_status
- **EMP-12 Sắp xếp:** Theo full_name hoặc started_at, ASC/DESC

> EMP-04 (cấp tài khoản — username/password): trong EMP-01 luôn (email + password initial). KHÔNG có endpoint riêng "cấp tài khoản" vì email = username, đã có khi tạo employee.
>
> EMP-05, EMP-06 (reset password, lock account, xóa account): Issue #04.

## API Endpoints

| Method | Path | Mô tả | Auth |
|---|---|---|---|
| POST | `/employees` | Tạo nhân viên mới + tài khoản | `@Roles('ADMIN')` |
| GET | `/employees` | Danh sách (pagination + filter + search + sort) | JWT |
| GET | `/employees/:id` | Chi tiết | JWT |
| PATCH | `/employees/:id` | Cập nhật (không sửa email, không sửa password) | `@Roles('ADMIN')` |

> Không có DELETE — xóa account làm ở Issue #04 (logic phức tạp: lock 30 ngày → delete).

## Acceptance Criteria

### A. DTO

- [ ] `CreateEmployeeDto`:
  - `fullName`, `phone` (regex VN 10 chữ số), `email` (IsEmail), `password` (min 8 max 128), `role` (IsEnum), `baseSalary` (IsInt min 0), `startedAt` (IsDateString)
  - **KHÔNG có** workStatus, accountStatus (mặc định ACTIVE), mustChangePassword (mặc định false vì admin nhập password trực tiếp)
- [ ] `UpdateEmployeeDto`:
  - `extends OmitType(PartialType(CreateEmployeeDto), ['email', 'password'])`
  - Thêm field `workStatus` optional (admin có thể chuyển sang ON_LEAVE/RESIGNED)
  - **KHÔNG** cho sửa email, password, accountStatus qua endpoint này
- [ ] `QueryEmployeeDto`:
  - `page`, `limit` (chuẩn skill)
  - `search?: string` — match full_name OR email, case insensitive
  - `role?: StaffRole`
  - `workStatus?: WorkStatus`
  - `sortBy?: 'fullName' | 'startedAt'` (default `startedAt`)
  - `sortOrder?: 'asc' | 'desc'` (default `desc`)
- [ ] `EmployeeResponseDto`:
  - Như `StaffResponseDto` ở Issue #02 nhưng admin được xem **thêm** `accountStatus`, `lockedAt` (vì admin cần biết tình trạng tài khoản)
  - **VẪN KHÔNG có** `passwordHash`

### B. EmployeeService

- [ ] `create(dto): Promise<EmployeeResponseDto>`
  - Check email duplicate → 409 `STAFF_EMAIL_EXISTS`
  - Hash password với bcrypt
  - Default: `work_status = ACTIVE`, `account_status = ACTIVE`, `must_change_password = false`, `locked_at = null`
- [ ] `findAll(query): Promise<{ data, meta }>`
  - Build filter: search ($or fullName/email regex), role, workStatus
  - Sort theo sortBy + sortOrder
  - Pagination với `Promise.all([find, countDocuments])`
- [ ] `findOne(id): Promise<EmployeeResponseDto>` — 404 nếu không tồn tại
- [ ] `update(id, dto): Promise<EmployeeResponseDto>`
  - Verify staff tồn tại
  - Apply dto fields (chỉ những field cho phép)
  - Return updated entity

### C. EmployeeController

- [ ] `POST /employees` `@Roles('ADMIN')`
- [ ] `GET /employees` (mọi role JWT đều xem được, vd: nhân viên xem list đồng nghiệp — discuss với Vu nếu cần restrict)
- [ ] `GET /employees/:id` `ParseObjectIdPipe`
- [ ] `PATCH /employees/:id` `@Roles('ADMIN')` `ParseObjectIdPipe`

### D. Testing

- [ ] POST tạo employee với role STAFF → 201, password đã hash
- [ ] POST tạo email duplicate → 409
- [ ] POST từ non-ADMIN → 403
- [ ] POST password yếu (<8) → 400
- [ ] GET list không filter → trả default page 1, limit 10
- [ ] GET list với search="Nguyen" → match cả "Nguyen Van A" và "nguyen@spa.com"
- [ ] GET list filter role=STAFF → chỉ STAFF
- [ ] GET list filter workStatus=ON_LEAVE → chỉ nhân viên tạm nghỉ
- [ ] GET list sort=fullName ASC → đúng thứ tự alphabet
- [ ] GET list sort=startedAt DESC → đúng thứ tự ngày bắt đầu
- [ ] GET list combine filter+search+sort → đúng
- [ ] GET detail không tồn tại → 404
- [ ] PATCH update full_name → success
- [ ] PATCH update email → bị ignore (không trong DTO)
- [ ] PATCH update password → bị ignore (không trong DTO)
- [ ] PATCH update workStatus = RESIGNED → success
- [ ] PATCH từ non-ADMIN → 403
