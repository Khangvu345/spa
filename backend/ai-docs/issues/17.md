**Status flow:**
```
PENDING_OTP ──(verify OTP)──→ CONFIRMED ──→ CHECKED_IN ──→ IN_PROGRESS ──→ COMPLETED
       │                          │              │
       │                          ▼              ▼
       └──────────────────────→ CANCELLED ←── NO_SHOW (chỉ từ CONFIRMED)
       └──(OTP expire/3 sai)──→ CANCELLED (auto)
```

**Phase 1 status default = CONFIRMED ngay** khi tạo (skip OTP step). Phase 3 OTP sẽ đổi default thành PENDING_OTP cho `source=LANDING_PAGE`.

**Indexes cần tạo:**
- `bookingCode` (unique)
- `staffId, scheduledStart` (compound — query slot availability)
- `status` (filter)
- `customerId` (filter)
- `scheduledStart` (sort)
- TTL index trên `otpExpiresAt` partial filter `status=PENDING_OTP` (phase 3 sẽ enable — phase 1 chuẩn bị sẵn)

### C. SlotAvailabilityService (helper, NOT controller)

**Đây là core logic — tách thành service riêng để Booking module và OPERATOR module reuse.**

```typescript
@Injectable()
export class SlotAvailabilityService {
  // Config
  readonly OPEN_HOUR = 8;        // 8:00
  readonly CLOSE_HOUR = 22;      // 22:00
  readonly SLOT_STEP_MINUTES = 30;
  readonly BUFFER_MINUTES = 15;
  
  async calculateSlots(serviceId, date): Promise<SlotInfo[]>
  async getSuggestedSlots(serviceId, date, count = 8): Promise<string[]>
  async getFullGrid(serviceId, date): Promise<SlotInfo[]>
  async isSlotAvailable(serviceId, scheduledStart): Promise<boolean>
}
```

**Logic `calculateSlots`:**

1. Lookup service → get `durationMinutes`, `cleanupMinutes` → `totalBlockTime = duration + cleanup`
2. Lookup staff phụ trách service qua `staff_service_assignments` → 1 staff duy nhất
3. Query bookings của staff đó trong ngày, status IN ['PENDING_OTP', 'CONFIRMED', 'CHECKED_IN', 'IN_PROGRESS']
4. Generate candidate slots từ `OPEN_HOUR:00` đến `CLOSE_HOUR:00` mỗi `SLOT_STEP_MINUTES` (8:00, 8:30, ..., 21:30)
5. Loại bỏ slot không đủ thời gian (`slotStart + totalBlockTime > CLOSE_HOUR`)
6. Với mỗi candidate slot, check overlap với bookings hiện có (kèm buffer 15 phút 2 đầu)
7. Trả về array `[{ time: 'HH:MM', status: 'FREE' | 'BUSY', bookingId? }]`

**Logic `isSlotAvailable`:**

- Gọi `calculateSlots` → check time có trong list FREE không
- Dùng khi POST /bookings để validate trước khi tạo
